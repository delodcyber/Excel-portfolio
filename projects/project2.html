Project 2

Analyze customer booking data to support management reporting and decision-making

Using the data provided, you have been asked to add some additional calculations and create a summary for management. The data provided contains information about the customers who have booked travel through various websites.

Data Requirements

  • Apply the filter feature to the whole range of data and use it to sort the customers alphabetically by their first name, A to Z. Leave the filter feature on (meaning you will still see little arrows on the first row of each column).
  • Create three named ranges for the "Customer Name", "Phone", and "Total Money Spent" columns. The range should include rows 2 to 587. These named ranges will make the following calculations much easier!
  • Create a new column named "Overall Ranking". Use the RANK.EQ function to rank the customers in descending order, meaning 1 will have spent the most money.
  • Create a new column labeled "Number of nights". Calculate the number of nights the customer stayed in the hotel using the "Check‐in date" and "Check‐out date" columns. (Hint: "Check‐out date" minus "Check‐in date")

Lookup Sheet Requirement

  • Use the Lookup Sheet, create a drop-down list of customer names by using data validation.
  • Use lookup functions to display the Room, Check-in dates, Check-out dates, Package, Ranking, and Number of Nights.
  • Use spreadsheet functions to calculate these items. Use named ranges to reference the data and show the results on the Lookup sheet. Think about how to display these calculations in a way that is easy for others to read and understand quickly.
  • Count the number of customers without a phone number.
  • What is total of the money spent across all customers?

Insights

The workbook must look professional, meaning that you should take time to clean up each worksheet. Here are some ideas:

  • Color each tab.
  • Format any currency columns with a dollar sign $.
  • Make the output and inputs cells stand out (i.e., bold OR color OR underline, etc.)
